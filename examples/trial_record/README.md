# Example trial record

One archived run, reproduced here verbatim except that absolute home paths have been
replaced with `$HOME/`. Large binaries (point clouds, RGB-D frames, evidence images)
are omitted; the manifest and the gate report are what make the record readable.

Read `quality_gate.json` alongside `manifest.yaml`: the manifest says what was
attempted and what the outcome was, the gate report says how much the perception
behind that decision could be trusted.
